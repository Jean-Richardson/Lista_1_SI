# Lista_1_SI
Primeira lista de implementação de sistemas inteligentes.

## Preparar o ambiente

Com Python instalado, crie e ative um ambiente virtual na pasta do projeto e instale as dependências:

```bash
python -m venv .venv
```

Linux/macOS:

```bash
source .venv/bin/activate
```

Windows (PowerShell):

```powershell
.venv\Scripts\Activate.ps1
```

Com o ambiente ativado, instale os pacotes:

```bash
python -m pip install -r requirements.txt
```

No VS Code, selecione o interpretador Python dentro de `.venv` para esse workspace.
Os scripts dos problemas 2, 3 e 4 podem precisar de internet para baixar os datasets.
